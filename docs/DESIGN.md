# Design system

BOB is a friendly ghost. Source of truth for tokens: `src/styles/globals.css`.

| Token | Dark (default) | Daylight | Use |
|---|---|---|---|
| `--bg` | `#0c0b16` | `#f6f4ff` | window background |
| `--surface` | `#15132a` | `#ffffff` | cards |
| `--text` | `#ece9ff` | `#1f1b3a` | body text |
| `--text-muted` | `#9a95bd` | `#6a6590` | secondary text |
| `--accent` (ectoplasm) | `#8affc1` | `#0f784f` | primary actions, ghost, glow |
| `--accent-2` (pumpkin) | `#ff9f5a` | `#a74c12` | status, highlights |

## Principles
- Spooky but warm. Soft glows, rounded shapes, slow floating motion.
- Clarity before charm: copy says what happened and what to do next.
- Motion is optional: `prefers-reduced-motion` disables animation.
- Native overlays (chip, menu) mirror these colors (Task 9 adds a synced Swift `Palette` plus a test).

## Layout
A sidebar holds the BOB title, the live orb and seven panels: Overview, Ghost Text, Selection Actions, Voice Dictation,
Brains, Personalize, About. First run opens a five-step welcome tour (welcome, permissions, brain, voice, cheat sheet).
About reopens it and holds the theme choice: Midnight (default), Daylight, or Match macOS.

## Orb states
idle (floats), listening (ring pulses), thinking (ring spins), haunting (glow: a suggestion is visible), error (pumpkin
ring plus BOB's message). The core derives the state from the commands the engines send to the helper
(`src-tauri/src/activity.rs`) and emits `orb-state`. The tray tooltip follows the same state. The native dictation orb
near the caret uses the same colors.

## Accessibility
- Contrast of at least 4.5:1 for every text and background pair in both themes, computed from the token values with
  translucent layers composited (`src/styles/tokens.test.ts`). The first run of that test failed 7 daylight pairs; the
  daylight accent, pumpkin, success, warn and danger colors were darkened (same hues) until all passed.
- The Swift `Palette` is parsed in the same test and must equal `--accent`, `--bg` and `--accent-2`.
- axe-core audits every panel and the welcome tour in Vitest. Color contrast is excluded there because jsdom has no
  layout; the token test covers it.
- Every control is a native button or input with an accessible name; `:focus-visible` draws an ectoplasm ring.
